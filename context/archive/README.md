# Original paper archive

This folder preserves the earlier 23-page paper and its historical source:

- [Original PDF](NAFSI_Predictive_Modeling_for_Agricultural_Resilience_original.pdf)
- [Original TeX source](NAFSI_Predictive_Modeling_for_Agricultural_Resilience_original.tex), formerly `artifacts/reports/neurips_2024.tex`
- [Original bibliography](references.bib)
- [SHA-256 manifest](manifest.json), recording the files' previous locations and unchanged hashes

The source and PDF were not fully synchronized before the rewrite. Both are preserved byte for byte. The TeX retains its legacy relative figure paths and dependency on the `neurips_2024` style; this archive is a historical snapshot, not a newly repaired build.

The current main paper is [Reading the Corn Belt](../../Reading_the_Corn_Belt.pdf), with [current TeX source](../../artifacts/reports/Reading_the_Corn_Belt.tex) and [build instructions](../../artifacts/reports/rewrite/README.md). Other files under `context/` remain ignored by Git; only this paper archive is included.
